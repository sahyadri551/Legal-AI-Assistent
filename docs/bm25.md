# BM25 retrieval

Milestone 4 builds a sparse BM25 index from data/processed/chunks.jsonl.

## Build

    $env:PYTHONPATH="src"
    python -m retrieval.bm25_cli build

Generated artifacts are written to data/indexes/bm25/ and are ignored by git.

## Query

    $env:PYTHONPATH="src"
    python -m retrieval.bm25_cli search "bail under section 439" --top-k 8

Results contain chunk ID, document ID, score, rank, metadata, and text.

## Design

- rank-bm25 BM25Okapi is used.
- Query and chunk text are tokenized deterministically.
- Results are sorted by score descending with stable index tie-breaking.
- The persisted index contains the BM25 object, corpus tokens, and original chunk records.
- No legal corpus or generated index artifacts are committed.
